05 // FAQ

Частые вопросы

Это бесплатно? Есть подвох?

Полностью бесплатно, без лицензий и телеметрии. Отказ от ответственности — в LICENSE.txt: ПО «как есть», не является медицинским изделием.

Оригиналы файлов в безопасности?

Да. Мост работает только с копиями в экспорт-папке. Источник никогда не модифицируется.

Как сайт узнаёт о новых версиях?

Через публичный GitHub API: при каждой загрузке страница запрашивает /repos/dosik74/DicomBridge/releases и перерисовывает блок скачивания. Новый релиз = новая карточка автоматически.

Несколько отделений на одном ПК?

Запускайте независимые копии: main.py --config D:\hosp1\config.ini --minimized. У каждой свой конфиг, очередь и имя профиля. Папки копий не должны пересекаться.

Строгий PACS отвергает файлы?

С v1.0.3 отправка идёт точечными контекстами + авто-транскод сжатых синтаксисов в Explicit LE. Плюс seen-кэш против дублей после рестарта.
